SHORT DESCRIPTION (summary — 132 char limit)
--------------------------------------------
Quality-of-life upgrades for claude.ai: project colors, bookmarks, asides, safer deletes, tab status, draft mode, XML export.


DETAILED DESCRIPTION
--------------------
Claude++ adds quality-of-life improvements to the claude.ai interface. It has no account, no backend, and no analytics of its own. Your settings and bookmarks follow you between your own Chrome browsers through Chrome's built-in sync; everything else stays on the device. Every feature can be toggled on or off from the toolbar popup.

🎨 Project colors
Assign a color to a project and its chats get their sidebar icons tinted to match, so you can tell at a glance which chat belongs to which project.

📁 Create project from a chat
Adds a "+ Create new project" option to the Add to project menu, so a loose chat can go straight into a brand-new project in one step.

🛡️ Delete guard
Deleting a project on claude.ai silently deletes every chat, file, and artifact inside it. Claude++ hardens that dialog: it names what's being deleted, warns you what's included, and makes you type the project name to confirm — so nothing is lost to a stray click.

🗂️ Grid or list view for project files
A project's Context panel shows uploaded files as a wall of unlabelled thumbnails. Claude++ adds a grid/list switch to that panel: list view gives each file a row that names it, and opening, multi-selecting and deleting files all work exactly as before.

🗑️ Delete file confirmation
Removing a file from a project's Context panel takes one click, and re-uploading is the only way back. Claude++ asks first — for a single file or a whole selection, in either view — naming what's about to go.

⏳ Thinking status in the tab title
Every claude.ai tab looks the same in the tab strip. Claude++ prefixes the title with a status glyph: ⏳ while a response is streaming, ✅ when one finished in a background tab, and ⚠️ if it ended with an error — so you know which tab needs you.

💬 Inline asides
Select any passage in a chat and ask a question about it. The answer streams into a card in the right margin, anchored to the text — like a comment beside a paragraph. Each ask runs in its own temporary conversation, so it stays out of your chat history.

🔖 Bookmarks
Select any passage and choose Bookmark to flag it, the way margin bookmarks work in an editor. The text stays highlighted and a bookmark appears in the left margin beside it; click it to clear. Bookmarks are saved per chat and survive reloads.

📑 Bookmarks page
A Bookmarks entry in the left sidebar opens a full page listing every bookmark across all your chats, grouped by project (or by chat, or not at all). Search it, click a bookmark to jump straight back to that passage, or delete one from its ⋮ menu.

😄 Emoji autocomplete
Slack-style emoji in the message box. Close a shortcode with its second colon (:tada:) and it swaps to the emoji in place, or type a colon at a word boundary to open a picker that narrows as you type — ↑/↓ to move, Enter/Tab or click to insert. The shortcode set ships with the extension, so nothing is sent anywhere.

↕️ Scroll navigation buttons
A small toolbar beside the scrollbar for getting around a long chat: jump to the start, to the previous message you wrote, to the next message you wrote, or to the most recent — no dragging required.

💾 Download chat as XML
Adds a Download button next to Share that saves the whole conversation as a structured XML file — roles, timestamps, and rich content (headings, lists, tables, code blocks, bold, italic, links) in a clean, machine-readable format. It fetches the full transcript, so nothing is missed in long chats, and follows only the active thread when prompts have been edited or replies regenerated.

⏸️ Draft mode
Inspired by Claude Code's Shift+Tab. Press Shift+Tab in the message box to arm Draft mode, where you can type, paste, attach, and dictate freely with no way to send by accident. Press Shift+Tab again to return to normal.

📝 Prompt stash
Press Ctrl+S (⌘S on macOS) to set a half-written prompt aside: it leaves the composer and waits in a card beside it. Press Ctrl+S on an empty box to bring it back, or stash a second prompt to swap the two. One slot per conversation, kept across reloads.

✏️ Edit queued messages
A message queued while Claude is replying can normally only be discarded. Hover one and a "Click to edit" hint appears above it, opposite the × that discards: click the message — or tab to it and press Enter — and its text comes back into the message box — added to the end of whatever you'd already typed — and it leaves the queue, ready to fix up and send again.

🔗 Open search results in a new tab
Results in claude.ai's ⌘K/Ctrl+K search are buttons rather than links, so Ctrl+click opens one in the tab you were already reading. This restores link behaviour: Ctrl+click (⌘+click on macOS), middle-click, or Ctrl/⌘+Enter on the highlighted row opens that chat in a new tab and leaves the palette open on its results, so several can be opened in a row. A plain click still navigates in place.

Privacy
Claude++ collects no data and sends nothing to any server of its own — it has none. It requires access to claude.ai only. Your feature toggles, project colors, and bookmarks are saved with chrome.storage.sync, so Chrome carries them to your other signed-in browsers; everything else (asides, stashed prompts, caches) stays on the device in chrome.storage.local. When you delete a chat or project, anything Claude++ saved for it is deleted too.

SINGLE PURPOSE DESCRIPTION
--------------------------
Claude++ enhances the claude.ai web interface with quality-of-life features such as color-coding chats by project, guarding against accidental deletes, showing response status in the tab title, inline asides, bookmarking passages, emoji autocomplete, a draft-composing mode, a prompt stash, editing a message queued while Claude is replying, opening a search result in a new tab, scroll navigation buttons, and downloading a chat as a structured XML file.

PERMISSION JUSTIFICATION — "storage"
------------------------------------
Used to save the user's per-project colors, feature on/off preferences, bookmarked passages, learned chat-to-project associations, inline asides, and stashed prompts. Preferences, project colors, and bookmarks use chrome.storage.sync so they follow the user between their own signed-in Chrome browsers; everything else uses chrome.storage.local. No data is sent to the developer or any third party.

PERMISSION JUSTIFICATION — host permission "https://claude.ai/*"
---------------------------------------------------------------
All features operate on the claude.ai interface. The content scripts read and enhance the page's DOM and observe claude.ai's own API responses to map chats to projects. Access is limited to claude.ai and no other sites.

DATA USAGE DISCLOSURES
----------------------
- Does the extension collect user data? No.
- Is data sold to third parties? No.
- Is data used for purposes unrelated to the item's core functionality? No.
- Is data used to determine creditworthiness or for lending? No.
Data stays on the user's device (chrome.storage.local), except for settings and
bookmarks, which Chrome's own sync (chrome.storage.sync) carries between the
user's signed-in Chrome browsers. Nothing is sent to the developer.
